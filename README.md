# DEALER — AI Commerce Arena

> **Commerce, negotiated.**

DEALER is an AI-driven commerce negotiation platform where autonomous Buyer and Merchant agents negotiate deals while deterministic business systems control what can actually happen.

The project explores how AI agents can participate in commerce without giving AI direct authority over business rules, deal state transitions, or financial transactions.
